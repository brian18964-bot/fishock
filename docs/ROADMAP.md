# 擴充規劃（待辦與已定案的方向）

這份文件記錄已經決定、但還沒實作的擴充方向，以及目前的系統要怎麼接上去。
做新功能前先對照這裡，避免現在的設計把未來的路堵死。

## 已定案的規則（2026-09-30）

| 項目 | 決定 |
|---|---|
| 幻想魚（幽靈魚、雙頭變異鯉） | 保留 |
| 螯蝦 | 算魚 |
| 魚的正式外觀 | 以程式生成的暫代模型為底再精修（`tools/export_fish_blend.py` 匯出每種魚的 .blend） |
| 售價 | 同種魚越大越值錢（`FishData.value_for_length`：最短 x0.8、最長 x1.25） |
| 海邊／城市的深水處 | 海邊岩石突堤、城市水泥堤岸平台（`Jetty`） |
| 死亡 | 帶進去的道具保留；魚貨、在地圖上撿到的裝備（背包格標記 `found`）遺失 |
| 商城購買 | 跳出視窗選數量與去處：裝備／放進背包／放進倉庫 |
| 基礎餌料 | 每輪開局自動給，但佔背包格（`Items` 的 `bait`，可移動、不能放回倉庫） |
| 地上的物品 | 魚會腐敗、大鬼會吃；道具不會壞 |
| 誘惑 | 最遠約拋竿的 3/4；丟完預設要重選，設定頁可開「自動選最便宜的魚」 |
| 魚缸 | 上限 10 條，滿了多的自動賣掉；特性目前只影響游法 |
| 閃光 | 基本扣滿格能源 20%，蓄力越久扣越多（滿蓄力 x2.5） |

## 待辦

- **小屋／村莊地圖風格**：素材由使用者提供（Witch cottage 或其他），到了再做。
- **主角模型**：使用者會提供特定角色模型，取代主畫面與裝備頁的人偶，並接上紙娃娃（帽子、上衣、背包欄位已預留，`CharacterViewer.SLOTS` 有頭、背、雙手掛點）。
- **魚的實拍照片**：使用者提供後用 `tools/fish_from_photo.py` 轉換。
- **魚缸擴充**：特性的實際作用（兇猛會攻擊、群聚…）、容量升級、繁殖或比賽等玩法，待定。

## 多人：合作與比賽

兩種模式都要做。

- **合作**：一起夜釣、湊獻祭額度；可以把道具或魚丟在地上給同伴（`DroppedItem`、`DroppedFish` 已可撿）；誘惑可以用來救被大鬼追的同伴。
- **比賽**：比漁獲價值等；**可以攻擊其他玩家**。
- **交換**：魚缸裡的魚可以跟其他玩家交換（魚缸頁已預留「交換」按鈕）。

現在要注意的事：
- 所有會改變世界的動作（丟、撿、獻祭、閃光、攻擊）將來都要能同步。新動作盡量寫成「一個函式、一個結果」，例如 `Player.put_item_down`、`GameState.sacrifice_at`，方便日後改成透過網路呼叫。
- 背包、倉庫、裝備的資料都在 `Profile`（每位玩家一份）；一輪中的狀態在 `GameState`。多人時 `GameState` 要拆成共用的部分（額度、供品池、天色）和每人的部分（身上的魚、誘餌）。

## 武器與戰鬥

- 可攜帶武器：**槍、刀、弓**等。
- **比賽**：可以攻擊其他玩家。
- **合作／單人**：可以獵殺地圖上的動物（目前的動物只是裝飾，要加生命值、掉落物）。
- 接法：
  - `Items` 加新的 `tab`（或沿用「裝備」）和新的 `slot`，例如 `weapon`。
  - 裝備頁多一個武器欄。
  - 武器佔背包格（刀 1×2、弓 1×3、槍 2×1 之類）。
  - 在地圖上撿到的武器標記 `found`，死亡會遺失。
  - 攻擊用右側控制區的新技能鈕，可以沿用光源技能鈕「拖曳瞄準、按住蓄力」的操作。

## 殺鬼彩蛋

- 鬼平常不能被殺死（只能用光定住、用魚引開）。
- 彩蛋：湊齊特定的**供品組合**（例如供品 A、B、C、D、E）後，才能擊殺鬼，或觸發特殊結局。
- 接法：供品池 `GameState.offering_pool` 目前只有稀有度與邪惡與否。要加「供品種類」欄位，再加一張「組合 → 效果」的表。

## 召喚

- 用供品或道具**召喚特定的魚或生物**。
- 接法：
  - 在 `FishData.pick_species` 加一個「強制魚種」的入口。
  - 在生物生成處（動物、鬼）加「召喚」的入口。
  - 觸發條件放在祭壇（用特定供品）或道具（使用後生效）。
