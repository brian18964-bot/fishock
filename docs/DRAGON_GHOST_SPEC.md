# 龍鬼（大鬼）角色規格 v1

> **已被取代**：遊戲現在用的是使用者在 Meshy 生成的龍鬼（Crimson Wyrm Warden），由 `tools/build_dragon_meshy.py` 減面、烘焙法線並綁上新的 40 骨骨架（每邊翅膀 5 骨、尾巴 7 骨），翅膀收合與拍動由 `scripts/dragon_rig.gd` 控制。以下為第一次外包時的規格，保留作紀錄。

這份規格交給外部美術（人或 AI）重做龍鬼的外觀。外觀可以自由發揮；**骨架與技術規格必須遵守**，
否則遊戲裡的動作、提燈、抓人互動會壞掉。

隨附檔案：

| 檔案 | 用途 |
|---|---|
| `DragonGhost_Tpose.fbx` | 目前的龍鬼，T 字姿勢，含骨架（72 骨）與蒙皮權重。**以這副骨架為準** |
| `tex/Dragon_texture_0.png`、`tex/Dragon_texture_1.png` | 目前用的龍皮貼圖（取自原始紅龍） |
| `DragonGhost_Tpose_views.png` | 正、側、背、斜四視圖。黃點：翅膀根部骨；青點：尾巴根部骨；紫點：手；綠點：頭 |
| 原始紅龍模型（使用者另附） | 龍頭、翅膀、尾巴、爪子的造型與皮膚來源 |

---

## 1. 外觀方向

- 一隻**以龍為首、雙足直立**的鬼：龍頭、四肢、尾巴、一對招牌翅膀。
- 體型參考 demonBasemesh：直立、肩寬、胸厚、手臂粗壯。
- 服裝參考舊的大鬼，但更簡單：一件**深色、下擺破爛的長袍**，從腰（或胸）到小腿中段。
- **皮膚材質全身一致**：頭、脖子、手臂、手、腿、腳、尾巴、翅膀的骨架與翼膜都用同一套鱗片皮膚（顏色與鱗紋要接得起來，不可以有「頭是一種皮、手是另一種皮」）。
- **翅膀要從背上長出來**：翅根要與肩胛處的背部皮膚**連成同一片網格**或無縫接合，要有肌肉／骨節的過渡。不可以是一片翅膀貼在背上。
- 尾巴同理：從尾椎（臀部後方）自然長出，不是插在袍子上。
- 手：可以是龍爪，但**必須有五根手指的形狀**（拇指＋四指），因為右手要提燈、雙手要抓人。
- 腳：龍爪腳（三趾前、一趾後即可），踩在地面上。
- **不要**做燈籠、武器或其他手持物（燈籠由遊戲掛到右手上，發綠光）。

## 2. 骨架（最重要）

**直接使用 `DragonGhost_Tpose.fbx` 裡的骨架，把新網格綁上去。** 不可以重建、改名、改父子關係，也不可以移動或旋轉任何骨頭的靜止姿勢（包含 bone roll）。

- 共 72 根骨，名稱如下（大小寫一致）：
  - 軀幹：`root`、`pelvis`、`spine_01`、`spine_02`、`spine_03`、`neck_01`、`Head`
  - 手臂（左右各一套，`_l` / `_r`）：`clavicle`、`upperarm`、`lowerarm`、`hand`
  - 手指（左右各一套）：`thumb_01..03`、`index_01..03`、`middle_01..03`、`ring_01..03`、`pinky_01..03`，每根手指另有 `*_04_leaf` 末端骨
  - 腿（左右各一套）：`thigh`、`calf`、`foot`、`ball`、`ball_leaf`
  - 翅膀：`wing_l`、`wing_r`（父骨：`spine_03`）
  - 尾巴：`tail_01` → `tail_02` → `tail_03` → `tail_04` → `tail_05`（`tail_01` 的父骨：`pelvis`）
- **可以加的骨頭**：只能加在以下骨頭底下當子骨。遊戲會讓 `wing_` 開頭的骨頭自動輕拍，`tail_` 開頭的骨頭自動擺動。
  - 翅膀骨節（例：`wing_l_02`、`wing_l_03`）
  - 下顎（`jaw`，放在 `Head` 下）
  - 尾巴更多節（`tail_06`…）
- 骨架單位：公尺；縮放 1.0；`root` 在原點、腳底在地面（z = 0）。
- 朝向：Blender 中**面向 −Y**、上方 +Z（匯出後在 Godot 中面向 +Z）。保持 FBX 裡現有的方向。
- 靜止姿勢：**T 字**（手臂水平伸直、掌心朝下），就是檔案中的姿勢。

主要骨頭位置（Blender 座標，公尺），網格要對齊這些點：

| 骨 | 位置 (x, y, z) | 說明 |
|---|---|---|
| `pelvis` | (0, 0.05, 0.92) | 髖 |
| `Head` | (0, −0.005, 1.57) | 頸頂；龍頭的旋轉中心 |
| `upperarm_l` / `_r` | (±0.19, 0.07, 1.44) | 肩關節 |
| `hand_l` / `_r` | (±0.74, 0.07, 1.44) | 手腕 |
| `wing_l` / `_r` | (±0.11, 0.175, 1.335) | **翅根：肩胛骨位置**，翅膀從這裡長出 |
| `tail_01` | (0, 0.20, 0.87) | **尾根** |
| `tail_05` | (−0.03, 0.91, 0.96) | 尾端前一節 |

## 3. 蒙皮權重

- 每個頂點**最多 4 根骨**，權重總和 = 1。
- 翅膀：翼骨與翼膜 100% 給 `wing_*`（及其子骨）；翅根周圍約 8–10 cm 與 `spine_03` 漸變，讓背部跟著動。
- 尾巴：沿 `tail_01..05` 平滑漸變；尾根與 `pelvis` 漸變。
- 龍頭：頭部 100% `Head`；脖子 `neck_01` ↔ `Head` 漸變，不可以出現頭與脖子之間的斷縫。
- 手指要個別綁定，至少拇指與四指分開（提燈與抓人會彎曲手指）。
- 長袍：綁在 `pelvis`、`thigh_*`、`calf_*`。在走路與奔跑時，腿**不可以穿出袍子**：袍子要夠寬，或下擺由大腿骨帶動。
- 不可以有沒綁到骨頭的頂點。

## 4. 網格與材質預算（手機遊戲）

- 總三角面數：**≤ 25,000**（目前約 22,000）。龍頭可以分到最多約 6,000。
- 網格數：1～3 個（例：身體＋翅膀一個、長袍一個）。所有網格共用同一副骨架。
- 材質：最多 3 個，使用 PBR（metallic-roughness）：
  - 皮膚／鱗片一個（全身共用）
  - 長袍一個
  - 眼睛或角，可以選擇另外一個
- 貼圖：PNG 或 JPG，**每張 ≤ 2048×2048**（建議 1024 或 2048）：
  - 必要：Base Color
  - 選擇性：Normal、ORM（AO／Roughness／Metallic 合成一張）
  - 不要用 UDIM，不要用程序性材質節點，因為遊戲讀不到
- 套用所有變形（Apply Transforms：位置 0、旋轉 0、縮放 1）。不要有修改器沒套用、隱藏物件、燈光、攝影機。
- **不需要做動畫**：動作由遊戲自己套上，包括待機提燈、殭屍走、追擊慢跑、抓、吃。

## 5. 尺寸與比例

- 在檔案中的大小：以現在的骨架為準，身體約 1.6 m 高、含龍角約 1.84 m（遊戲會等比放大到全高 2.76 m）。
- 最高點建議是龍角。翅膀尖端不要高於龍角太多，因為遊戲用全高來決定縮放，翅膀太高會讓身體變小。
- 翅膀展開寬度（T 字時）約 1.2～1.6 m；翅膀高度從肩胛到翅尖約 0.5～0.7 m。

## 6. 交付

- `DragonGhost_v2.fbx`（FBX 2020 binary，貼圖嵌入或附在 `tex/` 資料夾）；用 `.glb` 也可以。
- 正面、側面兩張 T 字截圖。

## 7. 收到後我這邊會做的檢查

1. 骨名、數量、父子關係、靜止姿勢與本規格一致（逐骨比對位置 ±1 cm）。
2. 每個頂點的權重數 ≤ 4、總和 = 1，沒有未綁定的頂點。
3. 三角面數、材質數、貼圖尺寸都在預算內。
4. 套上五個動作（待機提燈、走、追、抓、吃）各截圖檢查：
   - 翅根與背部無撕裂
   - 長袍無穿模
   - 右手提燈位置正確
5. 放進遊戲（`assets/models/run3d/dragon.glb`）實際跑一次夜釣截圖。
