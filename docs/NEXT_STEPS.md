# 下一步規劃（系統驗證後整理）

## 這輪驗證查了什麼
- 地圖完整性（森林、雪地各 2 個種子）：樹、石頭彼此不重疊、不站在水裡、出生點是空的；
  一個機器人在地圖上跑 22 秒，沒有進到任何實體裡，也沒有卡在空地。
- 樹幹碰撞：朝樹幹各角度全速推擠，角色停在樹幹邊緣。
- 完整釣魚流程（森林、雪地各 4 條）：打到結束，浮標收回、竿子模式放開、沒有殘留。
- 找到並修掉：教學關卡 1-1 在取消免費餌料後會沒餌可拋（關卡現在自帶一盒餌）；
  背包搬東西會蓋到包包裡的魚、又以「物品中間」當基準而亂跳（已修）。

## 還沒解決、但會讓玩家困擾的
1. **新手餌料經濟**：自由夜釣沒有免費餌，要買蚯蚓（1 元）。沒餌時只有一行提示。
   建議：沒餌且身上有錢時，提示直接導向商城；起始金幣夠買一盒。
2. **害怕狀態無法動**：被鬼追時被打到害怕 1.5–2 秒，可能連續被打死。
   建議：害怕結束後給 1 秒免疫，或害怕期間鬼的攻擊不連擊。
3. **小畫面實機效能**：在無頭與 xvfb 量不到真實 GPU。需在手機上看 fps 與第一次出招的卡頓。
4. **失敗原因說明**：斷線時 `snap_why` 有時為空，玩家看不到為什麼斷。
5. **雪地森林還只是第一版**：樹石是整體染白，沒有「只在頂面」的積雪；
   動物沒有雪地配色；沒有冰上釣點（冰洞）；音效沒有風聲。

## 建議的下一步（依價值排序）
1. **手機實機測試一輪**（一天）：拖曳（魚箱格子、背包）、竿子模式、小畫面、點外面關閉，
   記錄卡頓與誤觸，回報後逐項修。
2. **新手引導整理**（2–3 天）：教學關補上「竿子模式」「魚箱使用」「餌料」三個小教學；
   第一次沒餌時的導引；設定裡加「教學提示」開關。
3. **雪地森林第二階段**（3–4 天）：積雪 shader（頂面白、側面保留）、冰洞釣點、雪地動物配色、
   風聲與冷色音樂、雪地專屬關卡與成就。
4. **平衡調整**（持續）：用現有機器人跑大量模擬（各難度、各魚種大小），
   找出過難或過易的組合；害怕/混亂的頻率與時間。
5. **自動化巡檢納入每次提交**：本輪新增的三個巡檢測試（地圖完整、樹幹碰撞、釣魚流程）
   跑得較久，建議拆成「快速」與「完整」兩組。
6. **多人連線前置**：把魚箱、背包、倉庫的狀態改成可序列化的單一來源（目前分散在
   GameState / Profile 兩處），為之後同步做準備。
