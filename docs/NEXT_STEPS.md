- 新龍展翅（使用者回饋：新龍腕關節靠近身體又突出，飛行時看起來沒有展開翅膀）：
  - 原因：模型做的是半收的翅膀（手腕在肩膀旁邊、翼指往下），先前飛行是把它整片轉平，所以永遠展不開。
  - 全展開姿勢（`DragonRig.SPREAD_ARM/FAN`）：上臂、前臂往外伸成前緣（肘略往後、腕往前），
    三根翼指從手腕扇形張開（第三指往後指向臀部），每根指保留自己的弧度並拉直六成。
    翼膜因此要比模型大約撐開一倍；翼膜權重改成較柔和的分配（`SPAR_POWER` 4→2），撐開時像扇子一樣均勻，
    不會集中在兩指中間撕成一條；以 CPU 蒙皮量測，面積放大超過 3 倍的翼膜只剩 1%，飛行與蹲下測試都沒有撕裂。
  - 逐節展開／收合（`OPEN_RATE`、`OPEN_GATE`）：上臂抬離背→前臂伸出→手腕與翼扇打開→翼指伸直，
    每一節等前一節開到四成五才動；收翅反過來（翼指先收）；中途改變主意也是連續的。
  - 起飛（巡邏時約 2 秒，追擊時快一倍）：邊走邊展開、微蹲前傾，翅膀高舉到頂；
    接著兩下又慢又重的下拍（幅度 1.6 倍），第一下蹬起、第二下腳離地；之後平穩拍翅。
    拍翅上高下低（往下只到身體側面，不會繞到身體前面像披風）。
  - 降落：翅膀往前掠、前緣上翹兜風減速，下沉落地、腿接住重量（微蹲），翅膀張著停一下，再逆序收翅。
  - 觸發（`RunView3D._dragon_flight`）：依速度往前看夠遠（起飛所需時間×速度＋0.8 公尺）才起飛；
    轉向水邊太晚時整段加快，確保到岸邊已離地；在水上時，對岸近到只夠降落、且目的地在對岸之後才開始降落。
    高度由骨架決定（`DragonRig.airborne`）。
  - 陸上追擊翅膀保持收合（使用者要求）；抓住時翅膀半舉罩住；
    沒掙脫成功：時間到後有 1.6 秒「宣告」（`BigGhost.CLAIM_TIME`），期間心臟、強光、丟魚都無效，
    龍把翅膀大大張開高舉、膜面朝前緩緩起伏、挺胸抬頭，掙脫畫面變暗程度減輕、標題改成「逃不掉了……」，之後才被抓走。

## 還沒解決、但會讓玩家困擾的
1. **新手餌料經濟**：自由夜釣沒有免費餌，要買蚯蚓（1 元）。沒餌時只有一行提示。
   建議：沒餌且身上有錢時，提示直接導向商城；起始金幣夠買一盒。
2. **害怕狀態無法動**：被鬼追時被打到害怕 1.5–2 秒，可能連續被打死。
   建議：害怕結束後給 1 秒免疫，或害怕期間鬼的攻擊不連擊。
3. **小畫面實機效能**：在無頭與 xvfb 量不到真實 GPU。入場與第一竿已加預熱，仍需在手機上確認；
   若某個動作第一次出現仍會卡，把它加進 `RunView3D._rehearse_fx` 或預熱鏡頭角度即可。
4. **失敗原因說明**：斷線時 `snap_why` 有時為空，玩家看不到為什麼斷。
5. **雪地還缺的**：冷色音樂（目前只有風聲環境音）、雪地專屬關卡與成就。
